# UniProtKB news

## Cross-references to MDposit

Cross-references have been added to the MDposit database, the Molecular Dynamics Data Bank.

MDposit is available at [https://mddbr.eu/](https://mddbr.eu/).

The format of the explicit links is:

| Field | Description |
| --- | --- |
| Resource abbreviation | MDposit |
| Resource identifier | UniProtKB accession number |

Example: [P00918](https://www.uniprot.org/uniprotkb/P00918)

[Show all entries having a cross-reference to MDposit.](https://www.uniprot.org/uniprotkb/?query=database:mdposit)


### Text format

Example: [P00918](https://rest.uniprot.org/uniprotkb/P00918.txt)

```
DR   MDposit; P00918; -.
```

### XML format

Example: [P00918](https://rest.uniprot.org/uniprotkb/P00918.xml)

```
<dbReference type="MDposit" id="P00918"/>
```

### RDF format

Example: [P00918](https://rest.uniprot.org/uniprotkb/P00918.ttl)

```
uniprot:P00918
  rdfs:seeAlso <http://purl.uniprot.org/mdposit/P00918> .
<http://purl.uniprot.org/mdposit/P00918>
  rdf:type up:Resource ;
  up:database <http://purl.uniprot.org/database/MDposit> .
```
