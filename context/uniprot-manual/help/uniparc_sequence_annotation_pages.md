The UniParc Sequence Annotation Page is a dedicated annotation page as an
alternative for the deleted TrEMBL entries and for active entries from external
source databases found within a [UniParc](https://www.uniprot.org/help/uniparc)
entry. It shows the protein sequence data for a source-database record together
with automatically predicted sequence annotations generated by
[UniRule](https://www.uniprot.org/help/unirule) and
[ARBA](https://www.uniprot.org/help/arba) rules.

URLs take the form `/uniparc/{UPI}/entry/{xrefId}` (for example
`/uniparc/UPI0000000001/entry/Q12345`).

These pages are currently in beta and may change based on user feedback. We
welcome feedback through our [contact form](https://www.uniprot.org/contact).

# How to navigate to a Sequence Annotation Page

Aside from visiting the URL above, you can navigate to a Sequence Annotation
Page from within the UniProt website through several routes:

- When you click a cross-reference identifier in the cross-references table of a
  UniParc entry.
- When you select a [UniProtKB](https://www.uniprot.org/help/uniprotkb)
  accession that is no longer in UniProtKB due to
  [changes to reference proteomes](https://www.uniprot.org/help/refprot_only_changes).
  The page will show why the accession was deleted and provide links to the
  UniProtKB history page. Example:
  [https://www.uniprot.org/uniparc/UPI000296FDB7/entry/K4NZ49](https://www.uniprot.org/uniparc/UPI000296FDB7/entry/K4NZ49)

# What is shown on a Sequence Annotation Page?

The page has two tabs:

- **Entry:** the default display showing information from the UniParc,the source
  database record, plus predicted annotations. The annotations are complemented
  by graphical representations where appropriate. The entry tab can be explored
  by using the navigation bar on the left-hand side of the screen which lists
  shortcuts to each [section](https://www.uniprot.org/help/uniprotkb_manual) of
  the entry.
- **Feature viewer:** an interactive graphical representation of
  [InterPro representative domains](https://www.uniprot.org/help/InterPro_rep_domain)
  that are mapped to a protein’s amino acid sequence.

The toolbar at the top of the page provides
[BLAST](https://www.uniprot.org/help/blast-submission), Download and
[Add-to-basket](https://www.uniprot.org/help/basket) actions.

## Entry tab

The entry tab collects data from multiple locations:

- The UniParc entry for that cross-reference
- Predicted annotation using the automatic annotation systems
  [ARBA](https://www.uniprot.org/help/arba) and
  [UniRule](https://www.uniprot.org/help/unirule)

### Summary information from UniParc

The summary information section displays data taken directly from the
source‑database cross‑reference and the UniParc entry, including:

- [Protein name](https://www.uniprot.org/help/protein_names)
- [Gene name](https://www.uniprot.org/help/gene_name)
- [Organism](https://www.uniprot.org/help/organism-name)
- [Taxonomic lineage](https://www.uniprot.org/help/taxonomy)
- [Proteome](https://www.uniprot.org/help/proteome) that the protein is mapped
  to.
- Amino acids: the sequence length of the protein.
- Status of the cross-reference (active or deleted) and, if applicable, the
  reason it was removed from the source database.

### UniProtKB-like sections

Below the summary section, there are
[entry page sections](https://www.uniprot.org/help/uniprotkb_manual) that are
similar to that seen in UniProtKB. The entry tab can be explored by using the
navigation bar on the left-hand side of the screen which lists shortcuts to each
section of the entry that contains available data. These sections have been
populated with data from:

- UniParc sequence derived:
  - Predicted structure from
    [AlphaFoldDB](https://www.uniprot.org/help/structure_section)
  - [Similar proteins](https://www.uniprot.org/help/similar_proteins_section)
    which link UniRef clusters that contain this sequence, allowing you to
    explore related proteins.
- Predicted annotations: when available, the page shows predicted annotations
  generated based on the cross-reference’s UniParc entry sequence and taxonomy.
  If the taxonomy does not exist, annotation will not be generated. The two
  tools that are used to predict these annotations are described in the
  following sections.

#### Precomputed Annotation

Upon loading of the Sequence Annotation Page, precomputed annotation is fetched
and, if available, will populate the page. Precomputed annotation is available
for a subset of UniParc cross-references:

- RefSeq
- Entries removed from UniProtKB as part of the
  [reference proteome move](https://www.uniprot.org/help/refprot_only_changes).

The precomputed annotation is generated using the same
[ARBA](https://www.uniprot.org/help/arba) and
[UniRule](https://www.uniprot.org/help/unirule) rules used to generate
annotation for TrEMBL entries. Some aspects are absent, specifically:

- The feature domain pipeline is not used so the precompute will be missing
  domain names and features.
- Missing predictions from PIR and Google
- Missing Sequence Analysis Methods (SAM) so some features and specific keywords
  types will be missing
- GO predictions

The annotation is available for download directly from the API endpoint as a
JSON file. The download URL takes the form
`/uniprotkb/precomputed/{UPI}/{taxID}` (for example
`uniprotkb/precomputed/UPI0000000012/10245`)

#### Annotation via UniFire

The UniProt Functional annotation Inference Rule Engine
([UniFIRE](https://gitlab.ebi.ac.uk/uniprot-public/unifire)) is a rule execution
platform that processes rules, written in the UniProt Rule Markup Language
(URML), to generate automatic annotations for protein sequences by applying a
subset of UniProt annotation rules ([ARBA](https://www.uniprot.org/help/arba)
and [UniRule](https://www.uniprot.org/help/unirule)).

As this annotation is generated on demand, it will take more time to load than
the precomputed annotation. In the case that UniFire predicts no annotation,
only the UniParc information will be available for that Sequence Annotation
Page.

The annotation data is dynamically generated as a JSON file within your browser.

## Feature viewer tab

The feature viewer tab is a graphical display of a protein sequence, for
sequence annotation pages it displays
[InterPro representative domains](https://www.uniprot.org/help/InterPro_rep_domain)
which are protein signatures selected to best represent domain annotations from
multiple InterPro member databases and provide a non-redundant view of a
protein’s features
